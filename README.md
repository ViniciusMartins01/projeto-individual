# 🏍️ MotoByte

## 📌 Sobre o Projeto

O MotoByte é uma plataforma web desenvolvida como Projeto Individual do curso de Análise e Desenvolvimento de Sistemas da SPTech School.

O sistema foi criado com o objetivo de reunir informações técnicas sobre motocicletas em um único ambiente, permitindo que usuários consultem modelos, comparem especificações, realizem avaliações e salvem motos favoritas.

Além do catálogo de motos, o projeto conta com dashboard analítica, sistema de autenticação de usuários e funcionalidades de interação que transformam dados em informações relevantes para tomada de decisão.

---

## 🎯 Objetivo

Oferecer uma plataforma intuitiva para consulta e análise de motocicletas, auxiliando entusiastas e interessados a conhecer melhor diferentes modelos através de indicadores técnicos e estatísticos.

---

## 🚀 Funcionalidades

### Usuários

* Cadastro de usuários
* Login e autenticação
* Sessão de usuário

### Catálogo

* Visualização de motos cadastradas
* Informações técnicas detalhadas
* Página individual para cada moto

### Favoritos

* Adicionar motos aos favoritos
* Remover motos dos favoritos
* Ranking de motos mais favoritadas

### Avaliações

* Avaliação do sistema de 1 a 5 estrelas
* Comentários dos usuários
* Estatísticas de satisfação

### Dashboard

* Total de motos cadastradas
* Total de marcas cadastradas
* Total de usuários cadastrados
* Distribuição das avaliações
* Top 5 motos mais favoritadas
* Indicadores apresentados através do Chart.js

## 📊 Indicadores da Dashboard

O sistema possui uma dashboard analítica capaz de apresentar:

* Quantidade total de motos cadastradas
* Quantidade total de marcas cadastradas
* Quantidade total de usuários cadastrados
* Distribuição das avaliações dos usuários
* Ranking das motos mais favoritadas

Esses indicadores são atualizados diretamente a partir dos dados armazenados no banco de dados.
